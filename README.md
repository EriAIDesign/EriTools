# EriTools

1日1ツール開発。毎日ひとつ、引いたお題をブラウザで触れるWebツールとして作る。

完成度は目的ではない。毎日ちがう問いを持って作ることが目的。

---

## ルール

**お題は引く。選ばない。**
`000` の生成器が4枚のカードを引く。難易度を理由にした引き直しはしない。難易度を上げる追加は自由。

**成果物は必ず触れるWebツール。**
訓練テーマが何であれ、最後は GitHub Pages で動くものにする。実用品でもゲームでも誰得装置でもいい。

**時間制限なし。ただし一日で閉じられる大きさに削る。**
仕事と生活を壊さない。忙しい日は生成器を使わず適当に組む、あるいはお題を決めるだけでもいい。接触を切らさないことだけが条件。

**成果物の出来は評価対象外。**
しょぼい日は失敗ではない。何も分からなかった日も失敗ではない。

---

## お題の構成

| スロット | 意味 | 枚数 |
|---|---|---|
| MODE | どう考えるか | 7 |
| MATERIAL | 何を扱うか | 12 |
| LENS | どの角度から見るか | 24 |
| BAN | 何を奪うか | 17 |

デッキは [`deck.json`](deck.json)。

**MATERIAL は繰り返し出る。** 同じ素材を違うレンズで殴り続けるのがこの企画の芯。「時間」が3回出たら、3回とも別の練習になる。

**BOSS** は 1/7 の確率で出現し、通常のBANではなく呪い札を引く。整列禁止、均等余白禁止、一貫したサイズ禁止など、設計の癖そのものを封じる札。

## 構成

```
EriTools/
├─ deck.json      お題デッキ
├─ lab.json       実験台帳
├─ index.html     一覧
├─ 000-A/         お題生成器
├─ 000-B/         お題生成器（別実装）
├─ 001/
├─ 002/
└─ ...
```

各ツールは完全に独立している。共通化はしない。ひとつ壊れても他は動く。

`000` はカウント外。作業台であって作品ではない。

---

## 記録

[`lab.json`](lab.json) が台帳の正。1件につき以下を残す。

- 引いたカード
- 作ったもの / URL
- 使った技術（指定するものではなく、結果として何を使ったかの記録）
- 制作時間
- `learned` — その日ひとつ潰した概念。**任意**。空欄の日もある
- `quotes` — 制作中の発言から抜いたもの。逐語、整形しない

AIとの作業条件（AI Protocol）は7日ごとに固定して回す。何を作れるようになったかだけでなく、どう作ると自分が一番強いかを見るため。

---

## 進み方

短期の目標はない。潰していない角度が減っていくことだけが指標。

`#050` で生成器そのものを作り直す。100本回した後の設計判断が、最初の設計とどう違うかを見るため。
